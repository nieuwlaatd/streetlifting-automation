Privacybeleid

Laatst bijgewerkt: 13 september 2026

Wie

Streetlifting Dylan is een persoonlijk project van één persoon, die tegelijk de enige gebruiker is. Contact: nieuwlaatd@gmail.com.

Welke gegevens

Met toestemming via Google leest de app uit Google Health: lichaamsgewicht, vetpercentage, voedingslogs, slaap, verbrande calorieën en stappen. De app vraagt alleen leesrechten en schrijft niets naar Google Health.

Wat ermee gebeurt

Van de voedingslogs worden alleen dagtotalen bewaard (kcal, eiwit, koolhydraten, vet), geen afzonderlijke maaltijden of productnamen. Van slaap alleen de minuten per nacht. De gegevens worden gebruikt om een wekelijks trainings- en voortgangsrapport te maken voor de eigenaar.

Waar het staat

De dagtotalen worden opgeslagen in de GitHub-repository nieuwlaatd/streetlifting-automation. Die repository is op eigen verzoek van de eigenaar openbaar. Er worden geen gegevens verkocht, gedeeld met derden voor andere doeleinden, of gebruikt voor advertenties.

Toegang intrekken

Toestemming is op elk moment in te trekken via myaccount.google.com/connections. Daarna haalt de app niets meer op.

Google API-beleid

Het gebruik van gegevens uit Google-API's volgt de Google API Services User Data Policy, inclusief de eisen voor beperkt gebruik (Limited Use).

English summary: this single-user app reads weight, body fat, nutrition logs, sleep, calories burned and steps from Google Health with read-only access. Only daily totals are stored, in a GitHub repository the owner has chosen to keep public. Data is not sold, shared for other purposes or used for advertising. Access can be revoked at myaccount.google.com/connections. Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements.
